# Градиентный спуск для MSE

Учебное решение, близкое к исходному `ML/GD/gd.py`: класс
`GradientDescentMse`, градиент в цикле по признакам, явный шаг изменения весов
и история MSE. Без готового оптимизатора, статусов и откатов.

- [Код](gradient_descent_mse.py)
- [Небольшие математические проверки](test_gradient_descent_mse.py)
- [Что изменено относительно исходника](../RESTORATION.md)

`learn()` останавливается при малом изменении MSE (`threshold`) либо по лимиту
`max_iterations`. Первый критерий сохранён из упражнения и не доказывает
нахождения минимума: одинаковая ошибка возможна и при колебаниях.
При переполнении/неконечной ошибке обучение прерывается исключением.

Bias добавляется только вызовом `add_constant_feature()`. При `copy=True`
исходный DataFrame сохраняется. Строки признаков и targets сопоставляются по
позиции. Повторный `learn()` продолжает с текущих весов с новой историей.
Незавершённый исходный перебор параметров обозначен `NotImplementedError`.

## Проверки

Для класса и шести тестов нужны только NumPy, pandas и tqdm; unittest входит
в Python. Проверено на CPython 3.13.5, NumPy 2.5.4, pandas 3.1.1, tqdm 4.70.1
в целевой .venv без подключения исходного проекта. Из корня репозитория:

```powershell
.\.venv\Scripts\python.exe -I -B -m unittest discover -s 02-machine-learning/04-gradient-descent -p "test_*.py" -v
```

Проверены градиент, конечные разности, один шаг, прямая с bias, лимит шагов
и конечное завершение при колебаниях. Больших данных эти проверки не используют.

## Эксперимент с learning rate

[learning-rate-experiment.ipynb](learning-rate-experiment.ipynb) адаптирован
к простому классу и проверен через Run All в целевой .venv. На пяти точках
сравниваются learning rate 0.01, 0.1, 0.4, 0.6 при одинаковых начальных весах
и лимите 200 шагов. История содержит все рассчитанные шаги, без откатов.
При 0.6 ошибка растёт; при 0.01 лимит достигается до точного восстановления весов.

[requirements.txt](requirements.txt) фиксирует окружение. Для графиков нужен
matplotlib, для запуска и проверки notebook — ipykernel и nbformat; scikit-learn
в этом эксперименте не используется. Эти пакеты не обязательны для класса
и небольших тестов. Прежние файлы сохранены локальными снимками
в игнорируемой `.portfolio-local/02-machine-learning/before-style-restoration`.
