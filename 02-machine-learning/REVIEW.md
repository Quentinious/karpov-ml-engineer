# REVIEW: уроки 1–4

Этот файл фиксирует проблемы перенесённого кода. Они не исправлены на этапе 1.
Статическая проверка синтаксиса не подтверждает математическую корректность,
порядок исполнения, качество модели или авторство.

## Происхождение и авторство

Источник — локальная папка `KarpovCourse/ML`. Кандидаты выбраны в предыдущем
аудите и указаны владельцем репозитория для переноса. В исходном проекте не
обнаружен Git-репозиторий; metadata трёх notebooks не содержит подтверждения
индивидуального авторства. Формулировки LMS и `Your code is here` показывают
учебную основу, но не устанавливают автора заполненных ячеек.

Все четыре решения остаются **REVIEW**. Нельзя утверждать, что каждая строка
написана владельцем, либо что код является официальным эталоном. Подтверждённых
чужих решений в выбранной группе не установлено. Учебные Markdown-формулировки
пересказаны своими словами; комментарии и места для ответов сохранены. Неподтверждённые фрагменты
нужно атрибутировать или исключить перед публикацией.

Контрольные суммы и карта ячеек: [PROVENANCE.json](PROVENANCE.json).
Все индексы исходных ячеек в ней отсчитываются от нуля.

## Подготовка данных

Файл: [taxi-data-preparation.ipynb](01-data-preparation/taxi-data-preparation.ipynb).

- Исходные outputs содержат `KeyError` при повторном удалении координат и при
  группировке по `trip_duration`. Сохранённое состояние расходится с линейным
  выполнением исходных ячеек. Эти outputs не перенесены; причины требуют
  проверки последовательным запуском после согласования.
- `passenger_count` кодируется средним `trip_duration` на всей таблице. При
  последующем holdout/CV это создаёт утечку таргета; способ обучения и применения
  преобразования должен быть разобран отдельно.
- Результат записывается в `category_encoded`, исходный `passenger_count`
  удаляется. В предоставленном CSV урока 3 средние таргета находятся под именем
  `passenger_count`. Непрерывная воспроизводимая цепочка между этими файлами
  не установлена.
- Расстояние вычисляется через локальное приближение по широте/долготе.
  Это не длина автомобильного маршрута; допустимость приближения нужно оценить.
- Используются координаты конца поездки. Их доступность зависит от момента
  прогнозирования: адрес назначения может быть известен при заказе, фактическая
  точка завершения — нет. Предположение не зафиксировано.
- Повторное выполнение вычитания из `vendor_id`, преобразования координат и
  удаления колонок меняет состояние повторно либо падает.
- Экспорты `assignment_*.csv` создаются в рабочем каталоге. Они игнорируются Git;
  пути и назначение этих промежуточных файлов не менялись.

## Метрики регрессии

Файл: [regression-error-metrics.ipynb](02-regression-metrics/regression-error-metrics.ipynb).

- Явной ошибки в формулах MSE, RMSE, MAE и RMSLE статически не установлено.
  Численные результаты не пересчитывались; результаты старых outputs не перенесены.
- Перед RMSLE отрицательные прогнозы заменяются нулями в исходном DataFrame.
  Счётчики перепредсказаний/недопредсказаний далее относятся уже к изменённым
  прогнозам. Для сравнения метрик нужно явно оговорить эту семантику.
- RMSLE округляется до трёх знаков сразу при вычислении. Для последующего
  анализа лучше отдельно обсудить хранение полной точности и формат вывода.
- Есть готовые прогнозы двух моделей, но нет их реализации и протокола
  получения. Нельзя трактовать сравнение как независимую оценку собственных
  обученных моделей. Область RMSLE требует неотрицательного таргета.

## Линейная регрессия

Файл: [taxi-linear-regression-from-scratch.ipynb](03-linear-regression/taxi-linear-regression-from-scratch.ipynb).

- Сохранена формула `(X.T @ X)^(-1) @ X.T @ y`. Обращение матрицы требует
  невырожденности и чувствительно к обусловленности. Поведение на линейно
  зависимых признаках не проверено. Ручная реализация не заменена sklearn.
- FIXED при сверке с разбором: константа добавлялась первым столбцом, хотя
  условие требует intercept последним. Теперь единицы добавляются в конец;
  формула нормального уравнения сохранена. Порядок проверен на синтетических данных.
- Финальное упражнение по восстановлению предсказаний матричным произведением
  не реализовано. Пустая ячейка задания сохранена; работа остаётся неполной.
- В исходной ячейке после вызова матричного решения стоит `print()`, а сохранённый
  output показывает массив. Это ещё одно свидетельство устаревшего output.
  FIXED в целевой копии: в `print` передан результат вызова функции; вывод проверен
  на синтетических данных, полный CSV не запускался.
- Обучение выполняется на всей таблице без независимой оценки качества.
  Это сравнение коэффициентов, а не подтверждение обобщающей способности.
- Происхождение target encoding в `passenger_count` и соответствие данным
  подготовки требуют проверки; см. [описание данных](data/README.md).

## Градиентный спуск

Файл: [gradient_descent_mse.py](04-gradient-descent/gradient_descent_mse.py).

Восстановлен исходный учебный подход. `calculate_gradient`, `iteration`,
`calculate_mse_loss`, `add_constant_feature` совпадают с исходником по AST:
сохранены формулы, порядок действий, цикл градиента по признакам и явный bias.

Исправлены всегда истинное условие цикла и запуск при импорте. Вместо
расширенного механизма статусов и откатов оставлены лимит шагов, исходная
остановка по изменению MSE и исключение при неконечной арифметике.
Малое изменение MSE не доказывает математическую сходимость. Проверки входов
ограничены непустыми данными, формой одного таргета, размерами, конечностью
значений и допустимыми параметрами. Числовые DataFrame — ожидаемый вход.

Шесть небольших тестов проверяют формулу градиента, конечные разности,
один шаг, приближение к `y=3x+2`, конечный лимит и завершение при колебаниях.
Они выполнены в самостоятельной целевой .venv. Тесты дополнительных статусов,
откатов, диагностики и сравнение со sklearn убраны из основной работы;
прежние варианты сохранены локальными снимками.

Перебор параметров в исходнике был недописан и остаётся явной заглушкой.
[learning-rate-experiment.ipynb](04-gradient-descent/learning-rate-experiment.ipynb)
адаптирован к текущему простому классу и проверен через Run All на пяти точках.
При learning rate 0.6 MSE растёт до лимита 200 шагов; откатов в классе нет.
Авторство остаётся REVIEW. Список конкретных изменений: [RESTORATION.md](RESTORATION.md).
