## Что сохранено

Вычислительный код исходных кандидатов сохранён, включая ручное нормальное
уравнение и градиентный спуск. Исправления алгоритмов отложены до отдельного
разбора. sklearn в уроке 3 уже присутствовал в исходнике как средство сравнения.

В notebooks добавлены краткие вводные ячейки. Исходные Markdown-условия,
строки-комментарии с префиксом `###`, пустые и только комментирующие ячейки,
исторические outputs и execution counts не перенесены. Удаление этих материалов
не означает завершения недописанных заданий. Связанные с реализацией обычные
комментарии и docstrings сохранены; их авторство также требует REVIEW.
Python-файл дополнен только module docstring; остальное содержимое сохранено.

Карта файлов, индексы исходных ячеек и SHA-256 находятся в
[PROVENANCE.json](PROVENANCE.json). Из исходного проекта не переносились
Practice, официальные разборы, лекции, PDF и альтернативные решения.

## Данные и проверка

CSV не включены в репозиторий. Их состав, известное происхождение, хеши и
ограничения описаны в [data/README.md](data/README.md).
Текущий код использует относительные пути и ожидает соответствующий CSV
в рабочем каталоге notebook. Эти пути на этапе 1 не изменены.

Библиотеки, используемые переносимым кодом: NumPy, pandas, matplotlib,
scikit-learn, tqdm и Pillow (последняя импортирована в GD, хотя импорт выглядит
неиспользуемым). Зависимости не устанавливались и не фиксировались как проверенное
окружение. Исторические версии Python из notebook metadata: 3.7.3 и 3.12.11;
конфигурация исходного проекта указывает Python 3.13.5. Metadata не подтверждает
совместимость. Статическая проверка этапа 1 выполнена Python 3.13.5.

Проверяются синтаксис Python и кодовых ячеек, nbformat-структура, сохранность
вычислений относительно исходника, локальные ссылки документации и правила Git.
Обучение моделей, запуск GD и пересчёт метрик не выполнялись. Старые результаты
не представлены как результаты нового запуска.

Известные ошибки, ограничения и вопросы происхождения: [REVIEW.md](REVIEW.md).
