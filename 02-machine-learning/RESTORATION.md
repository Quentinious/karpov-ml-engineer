# Восстановление учебной структуры

Исходники KarpovCourse не изменялись. Перед правками изучен Git diff; текущие
версии сохранены локальными снимками в игнорируемой
`.portfolio-local/02-machine-learning/before-style-restoration`.

## Notebooks

Каждая исходная ячейка имеет тот же индекс и тип в целевом notebook:
42 ячейки HW1_new, 28 HW_2, 16 HW_3. Восстановлены пустые и комментирующие
ячейки, места `Your code is here`, промежуточные задания и пояснения.
Исходные Markdown-условия пересказаны своими словами без новых заданий.

На этапе восстановления код решений и обычные комментарии оставлены исходными. Только комментарии
с инструкциями экспорта/отправки ответа пересказаны в следующих ячейках
(индексы от нуля):

| Источник | Ячейки с пересказанными инструкциями |
| --- | --- |
| Metrics/HW1_new.ipynb | 11, 31, 36, 40 |
| Metrics/HW_2.ipynb | 7, 10, 16, 20, 23, 26 |
| LinearRegression/HW_3.ipynb | 8, 12 |

На этапе восстановления исполняемые строки HW1–HW3 не исправлялись;
их сохранность проверялась сравнением AST с исходниками. При последующей сверке
в HW3 исправлены порядок коэффициентов (свободный член возвращается последним)
и вывод результата матричного решения через print. Формула нормального уравнения
сохранена. Незавершённый ответ HW3 не дописан.
Сохранённые старые KeyError не перенесены как текущие результаты: три задания
не запускались на полном CSV. До восстановления в целевых трёх notebooks не
было актуальных outputs, поэтому подтверждённые текущие результаты не удалялись.
Ограничения target encoding и состояния ячеек остаются в [REVIEW.md](REVIEW.md).

## GD: необходимые отличия от исходника

| Место в текущем файле | Изменение и причина |
| --- | --- |
| Строки 20–62, __init__ | Сохранены исходные параметры и единичные веса; добавлен max_iterations. Проверяются форма targets, размеры, NaN/inf и положительные параметры; массив targets не склеивает несколько колонок |
| Строка 129, learn | `while True or ...` заменён на `while step_id <= self.max_iterations`: цикл имеет конечный предел |
| Строки 117–145, learn | Новая история при сохранённых весах; проверка конечности MSE, остановка исключением при переполнении, закрытие progress bar через finally |
| Строка 202 | Явный NotImplementedError вместо выполняемых заглушек с `...`: исходный перебор не завершён |
| Строка 205 и далее | Исходный пример из трёх строк помещён под main guard: импорт не запускает обучение |
| Импорты и конец файла | Неиспользуемый PIL.ImageChops.constant и неподтверждённые комментарии Output исключены |

Методы calculate_gradient, iteration, calculate_mse_loss и add_constant_feature
восстановлены из исходника без изменения их исполняемого кода. Сохранены названия,
формулы и расчёт градиента в цикле по признакам. Остановка по разности MSE —
исходный учебный критерий, не сертификат достижения минимума.

Из предыдущей расширенной версии убраны gradient_tolerance, converged_,
stop_reason_, n_iter_, error_message_, rejected_step_, откат весов и
классификация причин остановки. Большой набор тестов сокращён до шести
математических проверок; прежние файлы доступны в локальных снимках.

При восстановлении learning-rate-experiment.ipynb сохранялся отдельно. На финальной
проверке notebook адаптирован к простому API и выполнен через Run All с лимитом
200 шагов. AUDIT.md не изменялся. Новых CSV и больших вычислений нет.
