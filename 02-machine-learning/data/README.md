## Известное происхождение

Учебные таблицы содержат поездки такси Нью-Йорка: идентификаторы поездок,
временные отметки, число пассажиров и координаты. По содержимому они связаны
с NYC Taxi; точный первоисточник, версия выгрузки, лицензия и воспроизводимая
цепочка преобразования в локальных материалах не установлены. Ссылку на скачивание
именно этих файлов подтвердить нельзя.

Таблица `with_predictions` содержит `prediction_1` и `prediction_2`, предоставленные
в упражнении курса. Код и модели, создавшие эти прогнозы, отсутствуют в выбранной
группе. Таблица `with_target` уже содержит числовые преобразования и
`trip_duration`; `passenger_count` в ней представляет средние длительности,
а не исходное число пассажиров. Получение этого CSV из перенесённого notebook
подготовки не подтверждено: тот использует имя `category_encoded`.

В исходнике есть точный дубликат `taxi_dataset.csv` — `EDA/taxi_data2.csv`.
Дублировать его для воспроизведения не нужно.

## Ограничения воспроизводимости

- Код читает имена CSV относительно рабочего каталога notebook. Пути на этапе 1
  сохранены; единого загрузчика из `data/` пока нет. Возможное размещение локального
  входа рядом с notebook также исключено правилами `.gitignore`.
- Экспорты `assignment_6.csv`, `assignment_7.csv`, `assignment_8.csv`,
  `assignment_9.csv` — промежуточные результаты подготовки, не замена полным
  входам. Их исходные небольшие примеры также не переносились.
- Есть ошибки порядка исполнения, вопросы target leakage и расхождения
  сохранённого состояния; см. [REVIEW.md](../REVIEW.md).
- Для примера GD используются небольшие встроенные DataFrame, CSV не нужен.
  Импорт не запускает обучение: демонстрация помещена под main guard.
  Незавершённый перебор параметров не вызывается автоматически.
- До проверки происхождения и прав данные остаются локальными. Публичный Git
  содержит это описание, но не CSV, архивы, выгрузки или готовые модели.

Дальнейшая задача — подтвердить разрешённый источник, восстановить preprocessing
и согласовать способ получения локальных данных. Полные эксперименты на этапе 1
не запускались.
