# karpov-ml-engineer

Personal solutions and experiments from the Karpov.Courses ML Engineer program.
Task descriptions are brief summaries inferred from the implementations.

- [Applied Python](01-applied-python/README.md) — completed module; local solutions are being restored and documented.
- `02-machine-learning/` — current module, reserved for new work.
- [Repository audit](AUDIT.md) — exercise inventory, publication checks and unresolved questions.

Sections are independent exercises rather than a single installable package.
Database examples require an externally configured PostgreSQL database; data and
credentials are not supplied. Known limitations and provenance questions are
recorded alongside the relevant work.
